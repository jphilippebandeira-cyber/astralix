# Sistema de video v2 (11/10/2026) — substitui os fundos lisos
- Fundos: clipes reais livres (Mixkit, licenca gratuita, sem atribuicao obrigatoria): cidades, escritorios, pessoas no computador. Baixados no Chrome do Jean (pasta Downloads/mixkit_clips.tar), extraidos em v3/clips/.
- Montagem: reel.py + config JSON (lista de clipes com corte/pan para 9:16, legendas grandes com palavra-chave em amarelo, barra de progresso, selo ARE-IA).
- Musica: music.py gera trilha original (sem direitos de terceiros).
- Uso: python3 reel.py config.json -> name.mp4 (rodar em background, ~2-4 min).
- Regra: cada video = 1 dor concreta do publico (banco/grande empresa, recem-formado), cortes a cada 3-4 s, CTA "Comenta GUIA".
