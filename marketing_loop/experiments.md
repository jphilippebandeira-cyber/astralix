# Journal des expériences (le PDG lit ceci AVANT chaque passage et le met à jour APRÈS)
Format : hypothèse -> test -> résultat mesuré -> conclusion -> décision

## E1 (07/11) — CTA « question » au lieu de « Comenta MOT » (Astralix)
- Constat : TikTok @nexoaiii 731 et 714 vues mais 0 commentaire ; IG ≈ 40 vues.
- Hypothèse : une question facile (« preço, horário ou endereço ? ») déclenche des commentaires, qui relancent la distribution.
- Test : TikTok 07/11 07h45 (id 419639822) et 18h45 (id 419639874) ; Instagram TRIAL_REEL 20h00 (id 419639827).
- À mesurer : commentaires et vues vs 731 ; vues du Trial Reel vs ≈40 ; DM reçus.
- Décision à prendre : si commentaires > 0 -> répondre avec la démo et doubler le format ; sinon changer le hook (preuve à l'écran, chiffre vérifié).

- RÉSULTAT E1 (mesuré 07/11 17h20 BRT, +9h30) : TikTok « Dona de salão… » (texte fixe sur fond bleu, SANS voix) = 170 vues, 0 like, 0 commentaire vs 714/734 pour les POV voix+motion. IG : aucune nouvelle vente/DM ; Reels IG taux de visionnage >3 s = 23 %, durée moyenne ≈ 5 s.
- CONCLUSION E1 : la question n'a PAS déclenché de commentaires, et le format statique sans voix divise les vues par 4 (variable confondue -> la vidéo barbeiro 18h45 voix+motion+question donnera la comparaison propre). Le vrai goulot = les 3 premières secondes (77 % décrochent).
- DÉCISION : abandonner les vidéos texte fixe sans voix. Garder voix+motion.

## E2 (07/11) — CTA « valeur / SALVA » (conseil utile) au lieu de demander un commentaire (Astralix)
- Hypothèse : un conseil actionnable (« preço + 1 pergunta ») avec « Salva esse vídeo » dès la 1re seconde augmente la rétention 3 s et les enregistrements/partages -> plus de distribution qu'un POV pur.
- Test : TikTok voix+motion 08/11 12h30 (même format gagnant, seule la promesse change : conseil gratuit), + Instagram TRIAL_REEL 08/11 19h.
- À mesurer : vues vs 714-734 ; favoris/partages > 0 ; taux >3 s IG vs 23 %.
- Décision : si vues ≥ 700 et ≥1 favori -> série « 1 resposta pronta por dia » ; sinon tester un hook visuel (vraie capture de la démo astralixai.com).
