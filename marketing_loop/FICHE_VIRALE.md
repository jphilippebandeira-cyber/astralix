## 2. Ce que les chiffres disent

- **Hook à t=0, sans fondu : 14/14.** Le visuel de la promesse est déjà à l'écran à la première image (UI ChatGPT avec le prompt, bulle WhatsApp du client, texte en haut). Aucune intro, aucun logo.
- **Interface réelle = preuve : 13/14** montrent une UI (ChatGPT sombre, WhatsApp, reçu, notification). Les comptes sans visage qui dépassent le million (1, 3, 9, 10, 13) n'ont **que** l'UI et un texte.
- **Rythme : un changement visuel toutes les 1,5-1,8 s** sur les formats démo (1 : 1,5 s ; 2 : 1,6 s ; 14 : 1,8 s ; 8 : overlays toutes les 1-2 s ; 13 : une bulle toutes les 1-2 s). Les plans fixes de 7-9 s (7, 9, 10, 12) compensent par une lecture dense et une boucle.
- **Durée : médiane 16 s.** Démo / tutoriel : 17-27 s. Mème / capture unique : 7-9 s. Au-delà de 60 s, seulement pour les histoires de conversation (11, 13).
- **Punch-in : zoom plein écran sur le résultat** après chaque prompt (1, 2, 6), dézoom vers l'UI pour l'étape suivante. Légère poussée continue sur l'image finale (3).
- **Texte : 1 titre en haut (15-30 % de la hauteur, gras, blanc ou jaune avec contour noir, 3,5-5 % de la hauteur)** + sous-titres dynamiques de 1-3 mots (≈ 58-62 % de la hauteur, MAJ ou gras, contour noir) quand il y a de la voix (8, 14).
- **Boucle : 7/14 bouclent** (1, 7, 9, 12…), la dernière image renvoie à la première.
- **CTA « Comenta MOT » :** présent sur tous les gros comptes de prompts (8 « Codigo », Secreto, PROMPT, GUIA). Il arrive dans les 3 dernières secondes, en grand (~5 % de la hauteur).
- **Son :** soit une musique tendance de l'app (beat phonk / funk / lo-fi, sans voix) pour les formats sans visage (1, 2, 3, 7, 9, 10, 12, 13), soit une voix. Les sons d'UI sont rares mais présents sur les démos les plus soignées (1 : pop/clic à l'apparition des images ; 6 : sons subtils au résultat).

## 3. Fiche virale (cible gen2)

| Paramètre | Valeur cible |
|---|---|
| Durée | 18-24 s (démo), 7-10 s (mème/capture) |
| Hook | t=0 : UI + tension visible (prompt raté, cliente qui écrit à 23h47, tampon PARE). Texte ≤ 6 mots |
| Coupes | scène nouvelle toutes les 1,5-3,5 s + punch-in/micro-coupe toutes les 1,3 s => changement visuel ≤ 1,5 s |
| Zoom | punch-in 1,04-1,06 → 1,0 en 0,22 s à chaque coupe, alternance 1,0 / 1,05 tous les 1,3 s |
| Sous-titres | 2-4 mots, 72-86 px gras, blanc contour noir, zone y = 1180-1510 px (61-79 %), marge droite 150 px (boutons IG) |
| Mot-clé | boîte jaune #ffd23f texte noir (`*mot`) ou couleur d'accent (`^mot`), 1-2 par phrase |
| Visuels | UI réaliste plein écran (ChatGPT sombre, WhatsApp sombre, écran verrouillé), badge « EXEMPLO SIMULADO » |
| Son | sons d'UI seulement (frappe, envoi, notification, pop, whoosh). Pas de musique synthétique. Musique tendance ajoutée **dans l'app Instagram**, volume 10-20 % |
| Fin | CTA « Comenta MOT » avec le mot tapé dans un champ de commentaire, puis les 0,35 dernières s reprennent l'image du hook (boucle) |
| Vérité | aucun chiffre client inventé, aucune promesse de revenu, écrans simulés marqués comme tels |

## 4. Règles d'écriture

1. Hook = **interdit/erreur** (« PARE de pedir isso pro ChatGPT ») ou **scène vécue** (« 23:47. Salão fechado. Cliente chamando. »).
2. Montrer, pas annoncer : chaque affirmation a son écran (prompt → réponse, client → IA).
3. Une idée par Reel, 3 étapes au plus.
4. Avant-dernière scène = pense-bête à sauvegarder (« Salva esse vídeo »), dernière = CTA mot unique en majuscules (GUIA, ATENDENTE).
5. Mot du CTA = déclencheur ManyChat/DM existant.
6. Texte en portugais du Brésil familier (« pra », « tá », « te mando »).
